# Assignment 6: jQuery (Selectors, Effects, Animations)

Student: Duman Zhanybekov
Group: SE-2530

Small multi-page site that covers all tasks of Assignment 6. jQuery 3.7.1 is loaded from the CDN, so you need an internet connection.

## Pages
| Page | Tasks |
|------|-------|
| `index.html` | Task 0 setup, Task 1 selectors and CSS |
| `effects.html` | Task 2 show/hide, Task 3 fade, Task 4 slide |
| `dom.html` | Task 5 add/remove, Task 6 attributes, Task 7 form |
| `animations.html` | Task 8 basic, Task 9 sequential, Task 10 combined |
| `project.html` | Task 11 mini project: accordion menu |

The navbar at the top links all pages.

## How to run
Open `index.html` in a browser (or use Live Server in VS Code). Open the console (F12) to see `jQuery is ready!`.

## Deploy with GitHub Pages
1. Push the files to a GitHub repository.
2. Settings, Pages, choose branch `main` and folder `/ (root)`.
3. Wait a minute and open the link GitHub gives you.
4. Already deplyed pages website https://asleyvv.github.io/assignment-6/
