Task 11: Accordion menu

Mini project: an accordion. Click a title to open it, the other sections close with a slide animation.

What is jQuery?

A small JavaScript library that makes DOM selection, events, effects and animations shorter to write.

What does $(document).ready() do?

It runs your code after the HTML has loaded, so every element exists when you select it.

What is the difference between .text() and .html()?

.text() treats the value as plain text. .html() reads or writes HTML markup.

How does .animate() work?

You pass numeric CSS properties and a duration, and jQuery changes them step by step. Chained animations run one after another.
